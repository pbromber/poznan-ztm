# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-07

### Added
- Initial release
- Integration with ZTM Poznań API
- Real-time departure information
- Support for multiple stops
- Line filtering capability
- Two sensors: Next Departure and All Departures
- Custom Lovelace card with icons
- Vehicle features display (bike racks, A/C, low floor)
- Real-time vs scheduled indicator
- Config flow UI for easy setup
- Auto-refresh every 30 seconds
- Comprehensive documentation in Polish
- Example configurations and automations

### Features
- 🚌 Real-time bus/tram schedules
- 📍 Multiple stop support
- 🔍 Filter by line numbers
- ♿ Accessibility information
- 🎨 Beautiful Lovelace card
- ⚡ 30-second refresh interval
- 🇵🇱 Polish language support
